# DESIGN-FLOW-CANVAS: Flow 画布的空间与按需查看

Flow 用来辨认 Agent、查看真实活动和导航到已有会话与运行记录。画布不是第二套交付工作台，也不从运行事件推断用户关系。本设计延续 [ADR 0003](../adr/0003-commit-the-canvas.md)、[ADR 0006](../adr/0006-main-agent-and-subagent-roles.md) 与 [ADR 0008](../adr/0008-independent-run-records.md)，不修改协议或持久化格式。

## DESIGN-FLOW-IDENTITY: 身份、状态和选择分别表达

长期 Agent、开启编排的长期 Agent、可委派角色和共享角色引用保持不同身份。图标主体分别采用 46、52、40px；编排者、角色与引用另有标记。名称最多两行，模型次行只在有可靠信息或明确继承规则时出现。运行、失败、待回答、未读完成有独立徽标与文字；选中轮廓、连接起点和键盘焦点不覆盖状态。

`ProviderLogo` 集中管理本地品牌资产及颜色。供应商品牌只来自已加载会话的结构化 `model.provider` 或明确配置的 `provider/model`。裸模型 ID 只有在已有目录中唯一匹配时才识别。没有目录时不为取图标额外打开会话或请求模型。

首版识别 Anthropic/Claude、OpenAI（含 openai-codex）、Google/Gemini 的已知接入别名和 DeepSeek。聚合渠道、自定义 endpoint、不明模型使用中性首字母；不从模型名字猜品牌。继承调用者的角色保留继承文字和中性标记，不用最新一次 Run 冒充唯一模型。会话模型变化时直接重新投影。

品牌色只用于图标主体与摘要。状态使用状态色；普通边使用低对比专用 token。Logo 资源来自 Lobe Icons 的独立 SVG，随源码保留 MIT 许可与来源，不安装图标 SDK，也不在运行时请求第三方资源。现有 Lucide 操作图标继续使用。视觉层级和按需查看参考 affectUI Agent Graph，组件与算法独立实现。

## DESIGN-FLOW-INSPECTION: 扫视、摘要与完整详情

| 动作 | 行为与数据来源 |
|---|---|
| hover / 键盘 focus | 临时突出一跳邻域；不改变选中项，不创建会话 |
| 单击 / Enter / Space | 选择节点、切换轻量摘要；多选与连接操作保留原规则 |
| 摘要 | 使用已有名称、模型、状态、Goal/Brief 和最近 Run 任务或消息预览；不读取新的一份交付正文 |
| 完整详情 | 复用原节点操作与 ChatView；此时才按需打开绑定会话、加载模型目录 |
| 运行记录 | 复用原 RunPanel 及交付审查；共享角色继续携带调用者筛选 |
| 侧栏定位 | 直接打开完整详情并定位；双击长期节点仍打开完整聊天 |

物理显示节点 ID、规范 Agent ID 和调用者上下文分别保存。共享引用的选择映射到同一个角色，其摘要和详情仍知道来自哪个编排者。引用不会成为新 Agent 或新会话。成员活动计数按当前成员角色聚合：有活跃运行优先显示运行中，否则看该调用者的最新运行；历史失败不会与当前重试重复计数。

摘要在画布坐标投影后就近放到节点完整矩形外，宽约 280px；两侧不足时停靠底部并限制高度。初次停靠或容器尺寸变化时最小平移节点，后续普通平移不会被摘要拉回。摘要不缩放整图。

Esc 先退出当前工具菜单、连接状态或当前查看面板，关闭后将焦点还给入口。输入框、现有 Dialog 与菜单保留自己的键盘行为。摘要、详情与工具栏中的 Delete/Backspace 不透传为删除节点。完整详情关闭后不会再弹摘要。

## DESIGN-FLOW-SPACE: 真实分配空间，保留视口

详情和编排面板是画布的并列区域，互斥显示。桌面初值 380px；工作区宽度不足 860px 时改为上下分区，详情最多占 55% 高度。窄且工作区高度不足 480px 时显示完整详情，可由关闭按钮返回画布。沿用浏览器宽度不超过 768px 时不提供 Flow 的产品范围。

ReactFlow 始终获得实际剩余尺寸。`viewport.ts` 的 `focusViewport` 负责可读定位，`revealViewport` 负责尺寸变化后的最小平移。显式定位等待布局测量；执行期间尺寸观察不得打断定位。隐藏画布的零尺寸不参与视口计算。

恢复已有视口不猜测 `(0,0,1)` 是否表示未保存，不因节点数量、SSE、轮询或状态刷新重新 fit。定位所选使用约 0.85–1.1 的阅读比例；只有用户选择全图或整理后总览才允许缩小到 0.2。工具栏使用 ReactFlow 的真实缩放值，刷新后显示也保持一致。

画布工具包含缩放、全图、定位所选，以及收起的整理/撤回/缩略图菜单。缩略图默认关闭，偏好只保存在设备 localStorage。项目顶栏显示名称，完整路径保留在提示中。

## DESIGN-FLOW-LAYOUT: 显式整理和展示投影

`layout.ts` 仅接收真实节点、用户保存的通信边和 memberships，返回位置映射。按无向连通分组，用稳定 ID 排序和圆周初值做 180 次有限松弛：关联节点有吸引，所有节点相互排斥，弱中心约束防止分组发散。最后按完整矩形搜索最近空位，保证标签留白，再紧凑安放断开的分组。没有根、父子层级或固定深度列；环与横向关系参与同一二维排版。输入次序、边的方向、运行状态和临时调用边不影响输出。

整理通过原 `persist(..., commitGraph: true)` 一次提交位置，保留配置、关系和绑定。提供一次撤回，只恢复之前的位置。人工拖动会清除撤回；节点、边、成员关系或位置与整理版本不一致时，撤回不可用。普通视口与运行状态不使撤回失效。保存失败明确提示当前画布未保存，继续沿用保存队列；不宣称保存成功。

`members.ts` 只返回展示投影：按稳定 owner/member ID 决定主要节点与共享引用，使用完整节点矩形检查已保存节点及其他展开组，遇到冲突向下寻找空位。当前会话中人工拖过的真实节点保留位置。展开、折叠和共享引用本身不写入项目文件；只有显式拖动真实节点才提交其位置。

## DESIGN-FLOW-GEOMETRY: 同一套几何供布局和连线使用

`geometry.ts` 统一主体大小、节点静态尺寸和图标中心；实测尺寸优先于 164×154 的保守初值。定位、路由和投影使用完整矩形，包括名称、模型、状态及成员区。CSS 消费同一静态 token，避免另外维护锚点常量。

`routes.ts` 使用图标上、下、左、右四向端口。先比较直线、两种 L 形及两种中线折线候选，在无碰撞的候选中按路径长度、转弯成本和朝向目标的程度选择。按节点/方向分组，以相邻节点的几何位置和稳定 ID 排序分槽，避免边数组顺序改变出口。端点按稳定 ID 规范化，消息方向只反转路径，不改变几何。

其他节点始终以完整矩形加留白作为障碍。端点的连接段允许通过自身留白；底部先垂直离开图标，利用图标与文字间隙绕到完整矩形外，不穿过自身名称、模型、状态和成员区。间隙由几何 token 和 CSS 共同消费。候选均受阻时，复用障碍边界网格上的 Manhattan A*，每次路线选择最多做一次搜索；同侧分槽后重新校验。路径支持任意多个圆角，允许边互相交叉。这是有限候选与避障搜索的组合，不保证全局最优。

路由输入只包含几何和关系，序列化后的稳定输入用于缓存；消息脉冲和普通状态刷新不会重新求路。四向端口和几何分槽借鉴 affectUI Clean 预览的设计思路；保留 piflow 自身完整文字避障与多段搜索，未移植依赖中心/内外圈的参考规则。

实线表示用户关系，临时调用使用虚线并保留真实事件方向；二者只在展示层组合。选中边与邻域适度提亮，脉冲继续来自已有投递和 Run 变化。宽透明交互路径保留细线的命中区域，reduced-motion 使用静态活动数量。

布局在用户明确操作时做有限计算，没有持续力导进程或新图引擎。首版面向工程规模图，不承诺最优排版或布线。人工重叠可能使端口没有可行通道，此时使用确定性回退并用标签底色保护文字；不自动移动人工节点。大量障碍的有限网格搜索成本会增加，尚未对百节点密集图给出性能承诺；只有实测出现瓶颈时再替换搜索或布局实现。

## 验证入口

几何、定位、摘要位置、确定性布局、路由、成员投影与品牌识别使用现有 `node:test`；浏览器检查重点是实际尺寸、焦点、摘要不加载会话、引用调用者筛选和状态组合。使用隔离工程及合成活动，不把这些样本当成真实模型执行事实。

本轮未增加数据库表、协议字段、后台布局进程、模型调用入口或新运行事实。交付与审查继续由原 Runs/Reviews 模块管理。
