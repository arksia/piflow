# Flow 分层投影协作组，活动入口引用已有事实

Flow 总览只展示长期 Agent 及用户持有的 Link，进入编排者后展示成员和实际 Run；共享角色保持同一身份，非默认成员、已移除角色和审查分析只形成临时展示节点，组内位置与视口保存在本机而不扩展拓扑或新增执行账本。项目级关注由服务端组合全部 Runs 摘要与 Reviews 最新固定修订的范围状态，归属只取当前修订的来源 Run，待审、需修改、取消、执行异常与证据缺口分别表达；两个 SQLite 库提供一次组合观察，经事件失效和补读收敛，不承诺联合事务。

关注入口携带确定的 Run，或 Review / Revision / Target 身份，复用同一审查阅读器；新版出现时提示，人的当前阅读与决定不静默迁移。动效只消费通过版本检查的实时事件，首次加载、重连与历史补读不重播；代价是本地视图偏好和失效读取逻辑，收益是组织关系、执行事实与人工审查各有唯一归属，不把模型声明、已看或略过误作完成或批准。
