# Code 交付声明与宿主证据分别保存

Code 是每次 Subagent Run 显式请求的交付约定，不以角色名称推断。SubagentRuns 分别保存 Agent 的交付声明、pi 原生 bash 退出事实和宿主只读 Git 工作区采样，避免把自然语言“完成”、进程正常退出或工作区 diff 当作测试通过、需求完成或可合并的证明。

声明通过随 server 分发的固定 `submit_code_delivery` 工具提交，宿主再次校验有限结构并保存完整声明；不解析最终回复或读取约定文件。仅 Code Run 获得声明工具，基础工具权限保持收窄，继续禁止项目扩展自动发现。最后一次有效声明作为当前说明，先前声明保留在工具步骤中；声明后的工具活动和未关联本 Run bash 的检查引用均明确标注。

命令证据与原工具生命周期一同保存。退出码仅来自 pi 的结构化结果；缺少退出事实时保留未知，失败及重试分别记录，不根据最后一次成功覆盖先前失败。运行状态、命令退出码、进程关闭和交付声明各有独立含义，交付声明不控制 Run 成败，也不触发自动合并或额外检查。

Git 采集使用有时间和输出预算的本地只读命令，分别保存运行前、确认进程关闭后的工作区状态；它是跨时间段的共享工作区观察，不是本 Run 的补丁或作者归因。既有脏文件、已暂存、未暂存、未跟踪和已观察到的并发 Run 均保留；没有并发记录也不保证独占。产物路径只展示 Agent 声明，不据此读取任意文件。采集不可用不改变执行结果，未观察到关闭或重启后的历史缺失不通过重新采集补造事实。

交付记录归属现有 runs.sqlite，schema 2 事务迁移保留旧记录，历史缺失明确显示未采集。Run 和交付初始记录、工具事实和声明、最终状态和结束快照分别原子保存。SSE 在事务提交后只发送摘要和交付 revision；交付正文、命令分页和单步预览由现有详情界面按需读取，沿用项目作用域及认证。客户端按 revision 合并，收起后忽略迟到响应，重连刷新已加载页，失败明确提示可能过期。

本阶段复用 ADR 0008 的独立运行生命周期与记录故障语义，不建立第二套检查执行账本、通用 Agent 插件平台或工作区隔离机制。参考 Raven 对宿主事实和模型声明的区分，协议和实现独立设计。
